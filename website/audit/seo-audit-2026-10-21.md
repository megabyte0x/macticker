# Technical SEO audit, October 21, 2026

Method: the `seo-technical` checklist from [claude-seo](https://github.com/AgriciDaniel/claude-seo) (v2.4.2), applied to the prerendered build served locally, plus Lighthouse 13 mobile lab runs. Live checks (HTTPS, redirects, real headers, CrUX field data, indexation) need the production host and are listed under "after deploy".

## Findings and fixes

| # | Category | Severity | Finding | Fix |
|---|----------|----------|---------|-----|
| 1 | Indexability | Critical | Canonicals, og:url, sitemap, robots.txt and JSON-LD pointed at ticker.megabyte.sh, not the new macticker.app host. | `site` is https://macticker.app; every absolute URL is derived from it. verify-site.mjs fails on any old-host reference. |
| 2 | Indexability | High | The old host would serve duplicate content after the move. | Deploy a path-preserving 301 from ticker.megabyte.sh to macticker.app (deploy step). |
| 3 | JS rendering | High | FAQ answers were missing from the server HTML: Radix unmounts closed accordion panels, so crawlers and no-JS agents saw questions only. | `forceMount` keeps all five answers in the HTML; CSS hides closed panels. |
| 4 | Content accuracy | High | Homepage badge said "Ad-hoc signed release" while the download page, FAQ and checksum describe the Developer ID signed, notarized DMG (SHA-256 e0049e30…ab23 matches the bundled file). | Badge now reads "Signed & notarized". |
| 5 | Security | Medium | No Strict-Transport-Security or Content-Security-Policy. | HSTS (1 year, includeSubDomains) and COOP in `_headers`; Astro hashed CSP meta on every page, with no inline-style violations. |
| 6 | Structured data | Medium | SoftwareApplication lacked image, screenshot, publisher, file size and processor requirements; no WebSite/Organization entities; guides had no breadcrumbs. | `@graph` with WebSite, Organization and SoftwareApplication on the homepage; Article plus BreadcrumbList on guides with a matching visible breadcrumb. |
| 7 | Social/mobile | Low | No apple-touch-icon, theme-color or explicit twitter:title/description/image; og:image alt missing. | Added, and the social card was redrawn in the new design. |
| 8 | Performance | Low | Geist web font (32 KB) and an unprioritized LCP image. | System font stack (SF Pro on Macs); `fetchpriority=high` on the hero icon; WebP screenshot (19 KB vs 47 KB PNG) with PNG fallback; immutable caching for hashed `/_astro/` assets. |
| 9 | Accessibility (Lighthouse) | Low | Redesign regressions caught before release: `<dl>` children, kbd and eyebrow contrast, color-only inline links. | Fixed; all audited pages score 100. |
| 10 | IndexNow | Low | No IndexNow support for Bing, Yandex and others. | Key file in `public/`; submit URLs after deploy. |

Passed without changes: robots.txt allows crawling (no AI crawler blocks), XML sitemap excludes 404, 404 page is `noindex`, one `h1` per page, unique titles and descriptions, clean hyphenated URLs with consistent trailing slashes, viewport meta, no horizontal overflow at 390 px, all content prerendered (SSG), no history hijacking.

## Lighthouse (mobile lab, local build)

Home, download, guides index, two guides and privacy: Performance 100, Accessibility 100, Best Practices 100, SEO 100, Agentic Browsing 100. Home LCP 0.9 s, CLS 0, TBT 0 ms. These are lab numbers, not field Core Web Vitals or ranking evidence.

## Deployed October 21, 2026

Cloudflare Pages project `macticker`, production deployment 66bd0400. Verified on https://macticker.app:

- All seven sitemap URLs, robots.txt, both sitemaps and the IndexNow key return 200; unknown paths return 404. The DMG serves as application/x-apple-diskimage with an attachment disposition, and its SHA-256 matches the download page.
- HSTS, X-Frame-Options, nosniff, Referrer-Policy and Permissions-Policy headers are present; hashed assets are immutable.
- Single-hop 301s: http to https (Always Use HTTPS), www.macticker.app to the apex (redirect rule), and ticker.megabyte.sh / ticker-megabyte.pages.dev to the same path on macticker.app (`_redirects` deployment on the old project).
- Cloudflare Web Analytics auto-injection was turned off. Its beacon violated the CSP, and the privacy page states the site has no analytics tracking.
- IndexNow submission accepted (HTTP 202).
- Live Lighthouse mobile (home, download, a guide): 100 in every category; LCP 0.9 to 1.1 s, CLS 0.

Remaining manual steps: submit the sitemap in Google Search Console and Bing Webmaster Tools. CrUX field data will not exist until the site has traffic.
